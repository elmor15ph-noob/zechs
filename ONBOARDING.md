# DUO Brain — Team Onboarding

> **TL;DR:** Join the Discord server. Type `@Overlord` and ask anything.
> That's it. No install, no setup, no API keys.

---

## What is DUO?

DUO is the team's AI second brain. It runs 24/7 and knows:
- SAP SD / LE / Billing / O2C processes
- Project status and PM patterns
- Cross-domain synthesis (connects dots you didn't know existed)

It's accessed through **Overlord** — the team Discord bot.

---

## Step 1 — Join the Discord Server

Ask Jay for the invite link to the **DUO Brain** server.

Once you're in, find the `#duo-brain` channel (or DM Overlord directly).

---

## Step 2 — Talk to Overlord

Mention `@Overlord` in any message and the bot responds.

**No prefix = general assistant (Zero):**
```
@Overlord what is a condition technique in SAP SD?
```

**Use a prefix to route to a specialist:**

| Prefix | Agent | Best for |
|--------|-------|----------|
| `!heavyarms` | Heavyarms | SAP questions, fit/gap, config |
| `!sandrock` | Sandrock | Project management, risks, planning |
| `!altron` | Altron | Cross-domain synthesis, connecting ideas |
| `!zero` | Zero | General — anything else |

**Examples:**
```
@Overlord !heavyarms how does SAP handle partial delivery in SD?
@Overlord !sandrock what are the risks of a big-bang go-live?
@Overlord !altron how does our O2C process compare to Workday's?
@Overlord what's the difference between a sales order and a delivery?
```

---

## That's It

You're connected to DUO. No install, no vault, no config.

The bot is online whenever the DUO server is running. If Overlord doesn't respond, ping Jay — the backend may need a restart.
